#### 你说：

[https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)  
这个页面的方法论是什么？

#### ChatGPT 说：

这篇文章的方法论，核心不是“写一个更好的 prompt”，而是：

> **把 AI 设计从“一次生成”改造成一个「发散 → 批评迭代 → 收敛打磨」的 Agent 工作流。**

作者借鉴了 **Double Diamond（双钻设计流程）** ，重新改造成 3 个阶段： **Discover → Define → Deliver** 。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

### 1\. Discover：先扩大搜索空间，不要一上来就让 AI 做最终稿

普通 AI 设计容易长得一样：紫色渐变、左文右图、CTA、卡片。作者认为原因不是模型能力不够，而是模型天然倾向选择“最常见、最安全”的设计。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

他的解决方案有两个。

**方法 A：Seed String**

先从模型外部产生随机字符串，然后让 AI 根据这个字符串联想颜色、布局、字体和视觉语言。

流程大概是：

纯文本

`随机 seed    ↓ 解释 seed 中的模式    ↓ 生成 Creative Direction    ↓ 生成 UI`

关键点在于：

> **不要让 LLM 自己“假装随机”，而是给它外部随机性。**

这样可以把模型从默认设计分布里拉出去。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

**方法 B：大胆的 Design Brief**

不要说：

纯文本

`做一个漂亮的生产力 App landing page`

而是说类似：

纯文本

`做一个像像素游戏世界一样的 landing page 每个 section 像游戏场景 但整体仍然是可用的网站`

甚至：

纯文本

`极度不对称 冲突色 不舒服的留白 打破传统网页规则 但最后仍然要好看`

本质是：

> **先探索极端方案，再收敛，而不是从平均方案开始优化。** [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

### 2\. Define：用 Critic Agent 建立“审美反馈循环”

这是我觉得这篇文章里 **最值得你借鉴到 Agent 架构中的部分** 。

作者不让 Coding Agent 自己评价自己的设计。

因为：

纯文本

`Implementer: 我写的代码 ↓ 我知道为什么这么写 ↓ 产生路径依赖 ↓ 很难真正推翻自己`

于是引入一个独立的 **Design Critic Agent** 。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

架构变成：

纯文本

`          ┌──────────────┐           │ Implementer  │           └──────┬───────┘                  │               build                  ↓           Screenshot                  │                  ↓         ┌─────────────────┐         │  Design Critic  │         │  fresh context  │         └────────┬────────┘                  │               feedback                  ↓           Implementer                  │                  └──── repeat`

Critic **只看截图** ：

- 不看代码
- 不看之前为什么这么实现
- 不看之前的 critique
- 每次 fresh context

然后回答：

纯文本

`现在是什么设计语言？  如果顶级设计工作室来做，会是什么样？  当前最大的 gap 是什么？  最应该改的 3 件事是什么？`

文章里甚至让 Critic 打一个质量分，达到设定标准后才停止迭代。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

这里真正的方法论是：

> **生成模型负责执行，强模型负责 Taste / Judgment。**

比如：

纯文本

`便宜快速模型     ↓ 写代码 / 修改 UI  强模型     ↓ Critic / Art Director`

作者提到这种方式里，强 Critic 模型只占不到 10% 的输出 token，却能显著提高整体设计质量。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

这个其实非常接近你之前一直研究的：

纯文本

`worker → reviewer → worker`

只不过这里 Reviewer 不是 Code Reviewer，而是 **Taste Reviewer** 。

### 3\. Define：不要只让 Coding Agent 写 CSS

作者还有一个很重要的观点：

> Coding Agent 天然喜欢用“代码能轻松生成的东西”。

所以 AI 网站里会大量出现：

纯文本

`gradient 圆角卡片 几何图形 blur glow CSS pattern`

这也是所谓的 **AI 味** 。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

解决方式是主动给 Agent：

纯文本

`Image Generation Video Generation 3D / Shader`

即：

纯文本

`Agent  ├─ Code  ├─ Image Gen  ├─ Video Gen  └─ Browser / Screenshot`

让 Agent 自己选择媒介，而不是所有东西都硬用 HTML/CSS 实现。

---

### 4\. Deliver：最后阶段不是继续“加东西”，而是删

文章最后一个很重要的思想是：

> **AI 非常擅长增加元素，但很不擅长删除元素。**

AI 经常会不断增加：

纯文本

`标题 解释文案 badge 卡片 gradient glow container icon`

所以最后阶段主要做：

纯文本

`What can I remove?`

作者的例子里删除了：

- glow
- gradient
- 多余颜色
- 多余 label
- 多余 container
- 自定义但更难看的控件

转而尽量使用系统原生组件。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

所以完整流程其实是：

纯文本

`                 AI Design Loop  ① EXPLORE 大量生成不同方向         ↓ ② SELECT 人选择有潜力的方向         ↓ ③ DEFINE 建立 Design Identity         ↓ ④ IMPLEMENT Coding Agent 实现         ↓ ⑤ CRITIQUE 独立 Critic 看截图         ↓ ⑥ ITERATE 修改 → 截图 → critique         ↓ ⑦ ENRICH 图片 / 视频 / shader / motion         ↓ ⑧ REDUCE 删除所有没有价值的元素         ↓ ⑨ FINAL Production UI`

这篇文章最值得提炼成一句话的是：

> **不要把 AI 当“设计师”，而要把它组织成一个设计团队。**

对于你自己的 Agent，我甚至会把它进一步抽象成：

纯文本

`Explorer Agent    ↓ Design Director    ↓ Implementer    ↓ Visual Critic    ↕ Implementer    ↓ Polisher`

这其实比单纯做一个 design skill 更有价值：\*\*Skill 提供设计知识和规则，Agent Loop 提供搜索、判断和迭代机制。\*\*文章公开部分能看到 Technique 1–6；Technique 7 “Remove AI tells”之后进入付费区。 [Lenny's Newsletter](https://www.lennysnewsletter.com/p/how-to-turn-your-ai-into-a-world)

如果你准备把这套东西塞进 Mirage / Long-Agent，我认为最应该抄的不是 Seed Prompt，而是 **「Screenshot → 独立 Critic → 修改 → Screenshot」这个闭环** 。
