## 摘要

OpenAI 官方给出的 GPT Image（2.5）提示词与图像编辑实践指南。核心方法论：**先想清楚你要的图像，再描述主体、构图、风格与约束**；编辑时则**明确什么要改、什么必须保持不变**，一次只精修一个方面。文内提供从写实人像、精确文字渲染、logo 设计、漫画分镜、界面预览到科学教育视觉的生成范式，以及翻译、换装保持身份、透明抠图、草图写实化、多轮精修等编辑工作流，并给出各场景推荐的 `size`、`quality` 等 API 参数。

---

## 要点

- **生成三段式**：先定主体（subject）、再定构图（composition）、后定风格与约束（style & constraints）；编辑时单独声明「改动点」和「保持点」。
- **精确文字**：原样引用要渲染的文案，说明出现次数（如 exactly once），避免额外指令。
- **风格转移**：给参考图一个明确「角色」——只取它的调色板/纹理/媒介，新主体另行描述。
- **身份保持**：换装时逐项固定脸型、五官、肤色、体态、姿态、表情、发型、比例，只允许衣服变化。
- **透明抠图**：提示词要求隔离主体 + API 传 `background="transparent"`、用 PNG/WebP 保留 alpha、PNG 省略 `output_compression`；棋盘格不是透明度。
- **多轮精修**：把上一步输出当作下一步输入，每轮改动收窄到单点，便于判断哪步有效。
- **角色一致**：为书籍插画建立可复用的「角色参考」，换场景时重复其外观约束（同服饰、同五官、同配色、同气质）。
- **写实权衡**：追求「真实照片感」时明确要求去电影化——避免戏剧化打光、电影调色、摆拍构图，并指定自然细节与真实材质。

## 详细内容

### 生成范式与 API 参数

通用建议：先从你需要的图像出发，再用提示词描述主体、构图、风格与约束。针对 `gpt-image-2`，图像输入始终以高保真（high fidelity）处理，无需传 `input_fidelity`。

常见 `quality` 使用经验：信息密度高、含小字/图例/坐标轴的资产（幻灯片、图表、教学图）用 `quality="high"`；一般生成与编辑用 `quality="medium"` 即可。

### 生成（Generate）示例范式

- **写实人像**：指定面部细节（皱纹、毛孔、纹身）、拍摄手法（35mm 胶片感、50mm 镜头、齐眼平视中近景）、光照（柔和日光、浅景深、轻微颗粒）、并明确「不要美化、不要重度修图」。
- **信息图 / 流程说明**：点出流程名、受众、要传达的信息；对图表还要校验标签与事实关系，不只关注外观。
- **精确文字渲染**：引用要渲染的文案并说明出现次数，指定受众与视觉处理，不附加无关指令；禁用多余文字、水印、无关 logo。
- **可复用 logo 设计**：描述品牌与构成图形的形状，给出在不同尺寸下依然清晰的构图；用 `n` 请求多套变体；配合 `background="transparent"`、`output_format="png"`、`n=1` 输出透明底 logo。
- **历史 / 现实语境**：给出具体地点与日期（如 Bethel, New York, August 16, 1969）以锚定时代设定，但仍需人工检查服装、布景、环境的史实准确性。
- **故事转漫画**：把叙事拆成一个个清晰的「视觉节拍」，一屏一板；描述要具体、以动作为导向。
- **界面预览**：把产品当作「已经存在的成品」来描述，聚焦布局、层级、间距与真实界面元素，避免概念艺术式语言，结果更像可上线的界面而非设计稿。
- **科学 / 教育视觉**：按教学设计稿来提示——定义受众、教学目标、视觉格式、必备标签与科学约束；要求统一的扁平图标风格、清晰箭头、易读标签、充足留白；精确度高时显式列出必备组件并说明**不要包含什么**。
- **幻灯片 / 图表 / 图表类资产**：按「工件规格」而非插图请求来写提示词——点名交付物、画布与层级、提供真实文本或数据、描述视觉语言；添加可读排版、留白、禁装饰性杂乱等约束；用横版尺寸、`quality="high"` 承载小字与坐标轴。

### 编辑（Edit）工作流

编辑统一走 `client.images.edit` 并传入参考输入图；需本地蒙版的场景参考「using a mask」。

- **翻译且保持布局**：输入上一节的信息图，要求「把文字翻成西语，不改图像其他任何方面」，随后人工核对翻译与残留原语言文字。
- **转移视觉风格**：给参考图指定角色（取调色板/纹理/媒介），新主体单独描述，如「沿用输入图风格，生成摩托车手于白底」。
- **保持身份、只换服装**：把人像照片与多张服装参考作为输入，逐项固定人脸/肤色/体态/姿势等，只允许衣服变化；同一模式也适用于商品/物体必须保持可辨识的编辑。
- **组合参考**：图 1 是场景照片、图 2 是狗的照片，指定要移动的元素、目标位置与必须保持的部分。
- **透明产品抠图**：提示词要求隔离主体 + API 传 `background="transparent"`，用 PNG/WebP 保留返回的 alpha 通道，PNG 省略 `output_compression`；提示「棋盘格不是透明」；后续编辑需重复「保持透明底」的要求。
- **草图写实化**：把提示词当规格——保持布局与透视，再通过指定可信材质、光照、环境来「添加写实感」；加「不要新增元素/文字」防止过度再创作。
- **移除物体**：显式点出要移除的物体并保持周边不变；人物、姿态、光照、构图均保持不变，让编辑局部化。
- **把人插入场景**：指定自然光照、可信细节、身体取景、视线与场景交互；声明哪些五官与比例必须不变；`gpt-image-2` 省略 `input_fidelity`（图像输入总是高保真）。

### 跨轮精修（Refine across turns）

从一张输出开始，检查后再作为下一步输入；每轮跟进都收窄到单点，便于判断哪步改动有效。

- **建起点图像**：用上一节的洗发水抠图作为输入做广告牌场景，原样引用标签文字。
- **改变单一条件**：把上一轮广告牌输出作为下一轮输入，仅改天气（如「变成飘雪的冬日傍晚」）。
- **保持角色一致**：为多插图书籍建立可复用的角色参考——先确立角色的外观/比例/服装/基调，再换环境与剧情并重复外观约束（同绿色兜帽衫、同五官比例配色、同温和英雄气质、不重新设计角色）。

### 更多工作流

- **更换房间家具**：手术式写实——只替换单一物体（如白椅换成木椅），保持机位、室内光照、地面阴影与周边物体不变；指定写实接触阴影与织物纹理，让结果像真实照片而非重新设计。
- **节日贺卡**（原文另有案例）：描述场景、情绪基调、材质、光照与准确文案；对 3D 弹出卡或摄影卡需指定纸张层数、纤维、折痕与柔和棚拍光。
