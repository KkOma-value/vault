## 摘要

基于流传的一场约 3 小时 44 分交流会录音记录（@vista8 用 AI 整理）。梁文锋反复强调 DeepSeek "没钱、没卡、没名气、没有最顶尖人才"，却在两年内做出让全球紧张的东西。贯穿全场的一条底层逻辑是"**故意少赚**"：在一个足够大的赛道里，不精确计算眼前能拿多少，反而是拿到更多的前提——贪多的人会先被拿得更少的对手一层层挤出局。这套生存算法解释了 DeepSeek 几乎所有看似不划算的决定：主动压低利润、捡芝麻不恋战、不造芯片、选最省力的技术路线。**注意：本文是基于二手录音记录的转述，非官方发布。**

---

## 要点

- **少赚才能活**：假设 AI 吃掉全球 GDP 的 10%，谁想多拿份额，就会被愿意拿更少的对手用更低价打垮，链条一路下卷到平衡点。梁文锋更在乎"提高做成这件事的概率"而非"多拿份额"，而提高概率的方法恰恰是主动缩小想拿的部分。
- **开源与低利润是一体两面**：DeepSeek API 按十个月回本设计（约六倍利润），主动锁死上限。把利润压到"第三方靠开源自部署也无利可图"，用低利润而非闭源来保住市场本身。
- **捡芝麻 vs 西瓜**：去年 C 端流量、今年 B 端收入都是芝麻，随手捡；真正的西瓜是 AGI。做产品几乎是"无心插柳"——训练和 API 的出发点是通往 AGI 必经之路，用户和收入是路过的副产品。越大的愿景越能凝聚顶尖人才，人才优势溢出到产品层，形成降维打击。
- **不造芯片、不做垂直应用**：发电厂比喻——运营电厂不必自己造发电机。盘子足够大，只吃最擅长那块，"吃得太多反而先出局"。愿意帮阿里/智谱/月之暗面复现开源，因为市场够大时别人做得好不是威胁，别人做坏、搞坏生态信任才是损失。
- **技术阶梯（最省力顺序）**：思维链 → Agent → **持续学习** → 奇点（模型自迭代下一版、自己做研究，渐进非突变）→ 具身智能。当前 AI 与真正智能之间的墙是"必须被喂完整上下文"，跨过持续学习后 AI 能加速后续每一步研发。DeepSeek 训下一版模型**第一目标是让自己团队开发更快，而非外部用户用得好**。
- **算力是唯一瓶颈，人才不是**：约 2 万张 H 系列等效算力（多数近一两月到货），只撑得起几十 B 激活规模实验；训 800B 级需 5 万张 GB300 或 20 万张华为最新卡。判断 CUDA 护城河正被三股力量瓦解（AI 帮写代码降低建生态门槛、TileLang 快速重写算子体系、计算卡市场已超游戏卡使专用芯片成主流），未来一年内"国产芯片生态没问题"会被事实证明，剩下唯一障碍是产能。
- **半数核心研究员在标数据**：不是因为中国标注便宜（高端数据无成本优势），而是时间问题非资本问题——起步晚，预计一年内补上大部分差距。幻觉被归为可靠后训练改善的产品问题，会解决但非重点。
- **无组织的组织**：靠愿景驱动。管理分两条线——自上而下的集体项目（如发布 V4，叫"正式"）+ 自下而上人人自选研究（无 KPI）。梁文锋给自己定标准：**正式工作不占员工一半以上时间**，因为研究需要松弛环境。不模仿任何公司（包括贝尔实验室，因后者不需自负盈亏）。

## 详细内容

### 一以贯之的"生存算法"

文章末尾把所有决定归结为同一句话的不同写法：**在一个足够大的赛道里，不去精确计算眼前能拿到多少，反而是拿到更多的前提。**

| 表面决定 | 底层逻辑 |
|----------|----------|
| 克制不追最大份额 | 足够大的市场里贪多者先被挤出局 |
| 捡芝麻不恋战 | 盯眼前收益会耽误更大的西瓜（AGI） |
| 不造芯片、不做垂直应用 | 吃得太多反而先出局 |
| 技术路线选最省力顺序 | 省下的力气用在真正卡脖子处（算力） |
| 半数研究员标数据 | 算力差距补不上，只能靠更扎实的地基 |

### 追赶叙事

过去中国 AI 用别人 1/20 的算力、落后一到两年做出可比的东西；未来要把"落后时间"从一两年压缩到三到六个月，算力差距依旧——**不靠更多资源，而靠更聪明的方法**。华为拿到约 1.6 万张卡产能（相当于 4000 张英伟达卡），不指望靠它训更大模型，而是"帮华为把生态先跑通"、为未来铺路。华为 950 超节点性价比可平替英伟达 GB200/GB300，代价是"四张顶一张、落后两年"，贵 50%~200% 都无所谓，只要买得到。

### 可迁移的判断方法

面对"现在能拿多少"和"未来能拿多少"的选择时，先别急着算清眼前那笔账，问一个更根本的问题：**这件事会不会因为你现在拿得太多，提前招来一个愿意拿得更少的对手？** 若答案是会，再诱人的短期收益都不值得拿它去换活下去的概率。
