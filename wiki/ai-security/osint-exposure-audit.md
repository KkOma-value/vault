## 摘要

Blackbird、Maigret、SpiderFoot、theHarvester、Shodan 是五个开源的 OSINT（公开来源情报）工具，分别针对用户名、邮箱、域名、IP 和公网设备等线索。原文是针对具体个人与公司的侦察教程，本条目只保留防守侧用途：检查个人数字足迹、评估公司对外暴露面、清理遗留账号与泄露记录。

---

## 要点

- **工具分工**：Blackbird 与 Maigret 按用户名/邮箱查账号，SpiderFoot 做综合关联与泄露检查，theHarvester 按域名收集邮箱与子域名，Shodan 查公网暴露的设备与服务。
- **方法论**："先用快的工具看全貌，再用深的工具往下挖"，这也是自查时的合理顺序。
- **成本**：Blackbird、Maigret、SpiderFoot 无需 API Key；theHarvester 部分数据源和 Shodan 需要 Key（Shodan 有免费额度）。
- **防守价值最大**：公司侧看邮箱与子域名暴露、公网上的摄像头/NAS/后台、默认配置；个人侧看遗忘的老账号和被拖库的邮箱。
- **使用边界**：只对自己拥有的账号、域名、IP 和设备使用。未经授权对他人或他司资产做查询与扫描，可能违反法律和平台条款。

## 详细内容

### 工具速览

| 工具 | 输入 | 主要能力 |
|------|------|----------|
| Blackbird | 用户名、邮箱 | 跨 600+ 平台查账号，可生成 AI 画像，支持 PDF 导出 |
| Maigret | 用户名 | 覆盖 3000+ 平台，递归追踪同一用户名的其他账号 |
| SpiderFoot | 手机号、邮箱、域名、IP | 200+ 模块，覆盖数据泄露、暗网、子域名，输出关系图谱 |
| theHarvester | 域名 | 从搜索引擎、LinkedIn、DNS 等 40+ 来源收集邮箱、子域名、IP、URL |
| Shodan (Python) | IP 段或查询语句 | 查询公网暴露的摄像头、路由器、服务器、工控设备，支持脚本自动化 |

### 个人数字足迹自查

- 用自己常用的用户名和邮箱分别跑 Blackbird、Maigret，列出仍在线的旧账号，逐个注销或改密码。
- 把邮箱放进 SpiderFoot 检查历史数据泄露记录，据此决定是否改密、开启二次验证。

### 公司对外暴露面自查

- **theHarvester** 查自家域名：对外可见的员工邮箱数量与格式、子域名列表（容易遗漏旧站、测试环境）。
- **Shodan** 查自家公网 IP 段：数据库、后台管理界面、摄像头、NAS、打印机是否直接暴露，是否仍是出厂默认凭据。
- **SpiderFoot** 关联域名与 IP，检查是否出现在泄露事件或暗网售卖信息中。
- 服务指纹也是攻击者能看到的信息。Shodan 显示的软件与版本号，应通过隐藏版本信息和及时打补丁来处理，而不是放任暴露。

### 防守侧组合

- 用户名：Blackbird（全貌）→ Maigret（递归关联账号）→ 逐个清理
- 邮箱：Blackbird（账号）→ SpiderFoot（泄露记录）→ 改密、二次验证
- 域名：theHarvester（邮箱、子域名）→ SpiderFoot（深挖）→ 收敛暴露面
- IP：Shodan（端口与服务）→ 关闭不必要端口、修改默认凭据
