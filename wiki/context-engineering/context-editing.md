## 摘要

Claude 开发者平台的"上下文编辑"（context editing）把 [[context-engineering/effective-context-engineering|方法论]]里的工具结果清除等技巧做成了 API 能力：服务端自动清除历史中的工具结果或思考块，客户端 SDK 也能做基于摘要的压缩。它不只是省钱控长，而是运行时对"模型看到什么"的细粒度筛选，与提示缓存、记忆工具配合时有明确的取舍规则。

---

## 要点

- 三种方式：服务端工具结果清除（`clear_tool_uses_20250919`）、服务端思考块清除（`clear_thinking_20251015`）、客户端 SDK 压缩（通常更推荐服务端）。
- 上下文编辑在提示词到达 Claude 之前的**服务端**完成；客户端保留完整未修改的历史，无需双向同步状态。
- 工具结果清除按时间顺序清最旧的工具结果，替换为占位文本；可配置触发阈值、保留数量、每次至少清除量、排除工具，也可连工具调用参数一起清。
- 与提示缓存的交互是关键取舍：工具结果清除会使缓存前缀失效（要一次清够 token 才划算）；思考块**保留**时缓存得以延续、**清除**时缓存从清除点失效。
- 与记忆工具配合：清除前让 Claude 把关键信息写入记忆文件，支持超长工作流与按需回查。
- 客户端 SDK 压缩（TypeScript / Ruby 的 `tool_runner`）：生成摘要替换完整对话历史，适用面窄于服务端方案。

---

## 详细内容

### 动机

对话历史增长时优化成本和控制长度只是表层目标，更本质的是主动筛选 Claude 看到的内容：上下文是收益递减的有限资源，不相关内容削弱模型专注度。旧的工具结果（文件内容、搜索结果）被模型处理完就不再需要，留在历史里纯属浪费注意力预算。

### 服务端策略

**工具结果清除**（`clear_tool_uses_20250919`）：上下文超过配置阈值时，API 按时间顺序清除最旧的工具结果并替换占位文本，告知模型该结果已移除。默认只清结果，`clear_tool_inputs: true` 可连工具调用参数一起清。高级配置项：

- `trigger`（如 `input_tokens: 30000`）：超过阈值才触发。
- `keep`（如 `tool_uses: 3`）：清除后保留最近 N 次工具使用。
- `clear_at_least`（如 `input_tokens: 5000`）：保证每次清除的量值得一次缓存失效。
- `exclude_tools`：把特定工具排除在清除范围外。

**思考块清除**（`clear_thinking_20251015`）：管理扩展思考产生的 `thinking` 块（含交错思考下一轮内多个思考块的情形），在"多保留思考以维持推理连续性"与"多清除以省空间"之间用 `keep` 参数做取舍。

**与思考块有效性**：在较新的模型上，服务端上下文编辑不会使思考块失效；而客户端对较早轮次的编辑可能使之后每个助手轮次的思考块失效，新账户重放已失效思考块的请求会被拒绝，除非选择丢弃（有"保持前缀不变"一类机制配合）。

### 与提示缓存的配合

- 工具结果清除：清除会失效已缓存前缀，因此要配合 `clear_at_least` 一次清够；每次清除产生一次缓存写入成本，但后续请求可复用新前缀。
- 思考块清除：思考块被保留则缓存命中、输入 token 成本下降；被清除则缓存在清除点失效。配置 `keep` 时明确自己优先"缓存性能"还是"上下文可用空间"。

### 与记忆工具配合

记忆工具把信息卸载到上下文之外的持久存储：Claude 可在工具结果被清除前把关键信息写入记忆文件，让原本会超出上下文限制的工作流继续运行，需要时再从记忆文件查回，而不必让所有内容常驻活动窗口。这正是 [[context-engineering/effective-context-engineering|结构化笔记]] 思路的产品化。

### 客户端 SDK 压缩

基于摘要的替代方案（一般更推荐服务端压缩）：在 TypeScript / Ruby SDK 的 `tool_runner` 中可用，生成摘要并替换完整对话历史。文档涵盖压缩原理、配置选项、默认摘要提示、限制与监控，以及"何时使用压缩"的判断标准。

### 实操取舍清单

1. 工具调用量大 → 先上工具结果清除，配 `clear_at_least` 保证划算。
2. 开了扩展思考且在意推理连续性 → 思考块清除用保守的 `keep`；在意窗口空间则激进清除并接受缓存失效。
3. 超长任务 → 清除策略 + 记忆工具组合：清除前先写入关键信息。
4. 只有客户端 SDK 且无法用服务端策略时 → 退而使用 SDK 压缩。
