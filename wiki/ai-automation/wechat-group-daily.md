## 摘要

一个运行在本地电脑的 AI 自动化工具（作者 @Leobai825）：每天晚上 10 点定时，只读提取指定微信群当天聊天记录 → 本地脱敏（手机号/邮箱/身份证）→ 调用 AI 整理 → 生成 Markdown + PDF 双版本日报（压缩在 A4 一到两页）。它**不是微信机器人**——不发消息、不改记录，只从微信本地数据库只读提取。核心理念："AI 真正有价值的地方不是陪聊，而是嵌入现有工作流，每天自动完成一件原本需要人重复处理的事。"注意：文中默认接入作者自营的"薛定 Token"付费中转，属商业推广。

---

## 要点

- **触发方式**：Mac 用 launchd、Windows 用任务计划程序，每天 22:00 定时运行。
- **五步流水线**：只读提取当天群聊 → 本地脱敏 → AI 整理 → 生成 Markdown+PDF → 保存本地。
- **日报结构**：今日概览、核心讨论、已确认结论、待办事项、群内资源、尚未解决的问题——目标是"行动报告"而非聊天记录复制。
- **本地优先 / 隐私设计**：微信数据库只读，不发不改；脱敏在本地完成；API Key 存系统凭据库（Mac 钥匙串 / Windows 凭据管理器）而非配置文件；默认不额外保存原始聊天副本；只有脱敏后内容才发给第三方模型。
- **数据库密钥约束**：微信数据库密钥需从本机微信进程读取，Windows 首次初始化必须在已登录微信的电脑上用管理员 PowerShell 完成。
- **两种安装路径**：有 Codex 直接让它读 README 自动装配（涉及 sudo/管理员/重签名/输入 API Key 时先停下确认）；没有则跟 Mac/Windows 手动教程。
- **商业提示**：默认模型调用走作者自营的"薛定 Token"中转（模型 claude-opus-4-8）。作者坦言"本质上是商人"。**采纳时应把工具本身与其付费中转分开评估**——可自行替换为其他 API 端点。

## 详细内容

### 架构（本地优先）

```
微信本地数据库
   ↓ 只读提取指定群聊
本地脱敏（手机号/邮箱/身份证号）
   ↓
AI 总结
   ↓
Markdown（归档/可编辑） + PDF（A4 一到两页，给人看/转发）
```

不需要微信官方 API，可同时配置多个群，每群单独出一份日报。Mac 和 Windows 逻辑与输出格式基本一致。

### 值得借鉴的自动化范式

这个项目本身是个具体工具，但它示范了一类可复用的**本地 AI 自动化范式**：
- **只读 + 定时**：从已有数据源（本地数据库/日志/邮件）只读抓取，用系统级定时器（launchd/计划任务）无人值守触发。
- **脱敏前置**：敏感数据在离开本机前先在本地脱敏，只把处理后内容交给第三方模型。
- **凭据隔离**：API Key 进系统凭据库，不落配置文件、不进终端输出/截图。
- **产出双格式**：机器可续处理的 Markdown + 人可直接读/转发的 PDF。

### 风险与边界（作者自述）

- 自动脱敏无法识别所有商业秘密和个人信息；涉及公司机密、客户隐私、高敏内容的群不建议发给任何第三方模型。
- 使用前应确认自己有权处理相关群聊内容。
- 默认付费中转是作者的商业变现入口，非工具运行的必要条件。
